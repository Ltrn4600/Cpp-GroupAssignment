# Contributing

## Start a task

```bash
git switch main
git pull origin main
git switch -c feature/your-task-name
```

## Development guidelines

- Work only on your assigned task.
- Use clear names for files, classes, and functions.
- Do not commit executables or personal IDE settings.
- Compile and test before pushing.
- Coordinate changes to shared headers with the team.

## Submit your work

```bash
git add .
git commit -m "Describe your change"
git push -u origin feature/your-task-name
```

Open a Pull Request targeting `main`. Include a summary and testing steps.
